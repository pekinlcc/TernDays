体检第三批：小组件跨零点刷新、体验补齐与文档同步。
**本版同时包含 v0.9.2（手动更正缺口与跨年边界）的全部改动**——该版本在构建时发现一处跨模块
可见性错误，没有单独发布。

## 小组件

- **跨零点自动刷新**：v0.9 起天数会随时间变化（昨天的半天在零点补满 1 天、元旦换年），
  但刷新一直是纯打卡驱动的——凌晨到次日第一次打卡之间，小组件会一直比应用少半天，
  元旦凌晨甚至还写着去年。Android 排一个零点闹钟刷新，iOS 时间线额外给出一条零点条目
- **选择器里的预览不再是一整块空白**：真实布局的文字是运行时填的，现在用一份示例数据的预览布局
- 行数阈值随系统字体缩放放大（大字号下第三行此前会被裁掉）；朗读只念真正显示出来的行；
  小组件后台线程加了兜底，读库异常不会再把进程带崩

## 体验

- **补捕窗口已关的半天显示「未记录」**而不是「待记录」——不会再让人以为还会自动补上
- **打卡失败通知**不再让你「去设置里补记」（今天已经不在补记列表里），改为「打开应用会立即补打；
  已过窗口可在首页点『纠正』」
- **城市详情**里进行中的今天标「进行中」并说明「今天先算半天，另半天打上后补满」，
  不再和跨城日的半天混为一谈
- **导出预览**不再漏掉只有首点或纯手动补记的日子（首装当天此前完全没有预览）
- **迁移**：二维码页保持屏幕常亮；旋转屏幕不再重发密钥与端口（此前一转屏，手上那张码就作废了）；
  iOS 接收端加了 60 秒超时，旧手机息屏不会再永久卡在不可取消的「正在接收数据…」
- **只补进手动更正的那次导入**也会刷新界面与小组件（此前只有新增打卡才刷新）
- iOS：定位与城市解析移出主线程；导出页年份可横向滚动、回到页面会重新读数据

## 文档

README 计天规则表补上 v0.9 的「进行中的今天」；需求文档的迁移合并规则更新为 v0.9.1 的
`:core MergeRules` 口径并补上二维码地址校验；小组件章节补上跨零点刷新与预览；
iOS README 的小组件规格更正为 systemSmall。

## 已知未修

彻底解决需要在城市库里引入人口数据并升版重解析，留待后续版本。
