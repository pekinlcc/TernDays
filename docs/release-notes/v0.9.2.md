体检第二批：手动更正的缺口与跨年边界。

## 手动更正

- **不会再把半天更正静默升级成整天**：重新打开更正弹窗时，会显示这一天已有的手动更正
  （「已手动更正：上半天 → 北京」），并停在对应的半天上；此前默认回到「整天」，随手重选一个城市
  就把另半天一起吞掉了
- **只有一个半天样本时也能做半天更正**：进行中的今天只打了早点、或那天只有首点 + 晚点时，
  此前只能整天更正——而整天更正会把还没到的另半天也算成同一个城市
- **手动记录列表区分整天 / 上半天 / 下半天**：每行单独「恢复自动」，不再牵连同一天的另一条；
  iOS 上同一天的两条半天更正此前会因为 id 相同只显示一条
- **无记录的日子点「纠正」不再显示「当前判定：。」**

## 往年也能补记

设置页「补记无记录的日子」加了年份切换（此前写死当前年），往年漏掉的日子终于补得上。

## 跨年与边界

- **跨年后 1 月初的漏记现在算得出来**：「无记录」的起算点此前只看当年最早的记录，
  于是 1 月初永远排在它之前、永远不算漏记，年度天数静默少算。现在按全库最早记录判断
- **导出不再自相矛盾**：开始使用之前的日子不再在每日明细里写成一堆「无记录」；
  「无记录天数」从城市表的天数列里挪出来单独成行，并补上「合计（天）」
- **进行中的今天在导出里有标注**（「今天进行中，先计半天」），不再和跨城的 0.5 混为一谈
- **时钟回拨 / 导入未来时间戳**不会再让行程连续性无限有效
- **坏的时区 id**（换机导入或系统下线的旧 id）不会再让首页与导出崩溃
