v0.1 发布后的首个体验与质量补丁。

## 变化

- **首页权限警示**（Android + iOS）：跳过引导或权限被收回时，首页顶部会出现「自动打卡还没就绪」的警示条，点击直达设置——避免以为在自动统计、实际权限没给全的情况
- 修正城市详情页在数据未加载时可能显示异常占位文本的问题
- 发布流程修正：从本版起 Release 的 tag 正确指向实际构建提交（`v0.1` 的 tag 因发布动作默认行为误指向仓库初始提交，且受 GitHub 权限限制无法由 CI 自动改正，详见 v0.1 发布说明的注记）

## 质量

- 新增内置离线城市库的集成测试：文件格式合法性、3.4 万点规模校验、10 组关键城市坐标（杭州/北京/深圳/昆山→苏州/廊坊/港澳/东京/大阪/新加坡）解析断言
- 导出文件经外部工具实测：openpyxl 正常打开 xlsx 双分表、数值单元格类型正确；CSV 带 BOM + CRLF，Excel 打开无乱码

安装方式与已知限制同 [v0.1](https://github.com/pekinlcc/TernDays/releases/tag/v0.1)。
