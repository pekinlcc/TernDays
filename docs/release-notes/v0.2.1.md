按反馈精简 v0.2 的桌面小组件。

## 变化

- **小组件只显示最关键的信息**：今年 Top 3 城市及天数（去掉了大数字统计与今日打卡状态行），加一行小字的年份作为上下文
- **刷新改为纯打卡驱动**：
  - Android 取消 30 分钟周期轮询（`updatePeriodMillis=0`），只在打卡 / 补记 / 开机 / 添加小组件时刷新——正常情况每天随早晚两次打卡各刷新一次
  - iOS 时间线只在每个打卡时间点之后兜底刷一次，应用内打卡 / 补记时主动刷新
- 摘要口径同步精简，单元测试更新（:core 共 26 个测试）

安装：从 [Releases](https://github.com/pekinlcc/TernDays/releases) 覆盖安装即可，数据与已添加的小组件保留。
