新功能版本：**首点**——首次安装立即打一个点，并定义了它参与计天的规则。

## 首点（Android + iOS）

装完 App、完成权限引导后**立即**记录一次当前位置（无论几点），首页今日卡会显示
「首点 HH:mm · 城市 ✓（已记录当前位置）」——不用等到 7 点/17 点才看到第一条数据。

### 计天规则（一天永远最多 1 天）

一天 = 上半天样本（早点）+ 下半天样本（晚点）。首点不占早/晚槽，只做**兜底**：

- **凌晨装机（早于 7 点）**：当天打 3 个点；早晚正式点优先，首点只在早点没打成时顶替（凌晨位置≈早上城市）
- **下午装机（12–17 点）**：当天打 2 个点；首点与晚点**同属下半天，不会拆出两个半天**，
  按单样本规则整天 +1；若 17 点没打成，首点顶替晚点，装机当天照样计数
- **半天只产生于「上半天城市 ≠ 下半天城市」**：例如凌晨在 A 城装机、早点缺失、晚上到 B 城 → A +0.5、B +0.5
- 手动补记依旧优先于一切打卡点

明细与导出中首点以「首 HH:mm 城市」显示（导出在备注列）。
