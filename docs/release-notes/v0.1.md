TernDays 首个版本：统计一个自然年里你在每座城市各待了多少天。

## 下载安装（Android）

下载下方 **TernDays-v0.1.apk** 安装（Android 8.0+）。APK 为自签名，安装时系统会提示「未知来源」，允许即可。

首次启动请按引导完成：

1. 定位权限「**始终允许**」（后台定点打卡必需）
2. 通知、精确闹钟、忽略电池优化
3. 国产 ROM（小米/华为/OPPO/vivo 等）务必在设置 →「打卡保障」里把 TernDays 加入**自启动白名单**，否则后台打卡会被系统杀掉

## 核心功能

- 每天 07:00 / 17:00 各自动记录一次 GPS 定位，离线解析成城市（不联网、无账号，数据全部在本机）
- 计天规则：早晚同城 = 该城市 +1 天；早晚异城 = 各 +0.5 天；只有一个点 = 该城市 +1 天；全天无记录可手动补记
- 首页年度「城市 × 天数」列表 → 点进城市看月历（全天/半天标记）和打卡明细
- 按年导出 Excel / CSV，经系统分享面板保存

## 已知限制

- 城市边界附近可能判给邻市（离线最近点匹配）；原始坐标已保存，后续版本可重新解析历史记录
- 后台打卡成功率取决于系统调度，请完成「打卡保障」的全部设置项
- iOS 版本本次提供源码（`ios/` 目录，Xcode 自行构建），尚未真机验证
