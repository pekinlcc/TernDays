体验与一致性版本——全面体检 76 条发现的第二批(体验批)全部落地。

## 深色模式 🌙

双端跟随系统自动切换,浅色/深色两套完整色板,小组件同步适配。此前 iOS 在深色模式下「更正城市」的文字对比度只有 1.03:1(几乎看不见),现已彻底解决;Android 也关闭了 OEM 的「强制深色」,不会再被第三方反色破坏配色。

## 半天粒度更正

跨城出行日终于能只改错的那半天:当天有早/晚两个样本时,更正对话框多出「整天 / 只改上半天 / 只改下半天」选择。选半天后另一半天仍按打卡判定,**保住正确的 0.5 + 0.5 拆分**,不再被迫把一整天归给一个城市。整天更正与半天更正互斥,随时可恢复自动判定。

## 城市搜索

- **拼音可搜**:beijing / shenzhen / shanghai 都能搜到
- 结果按 **全等 > 前缀 > 包含** 排序,中国城市优先——搜「伦敦」不再先跳出加拿大的那个
- 重名城市带**国家/地区标注**(英国·ENG / 加拿大·08),一眼分得清
- iOS 搜索移到后台线程,3.4 万行全表扫描不再卡输入

## 双端一致性

- iOS 补齐:回到前台自动刷新数据、拿不到定位时发**打卡失败提醒**、城市库重解析完成后有**提示条**(此前静默)、导出加「首点」列与明细预览卡、生成中有进度、失败明确报错(此前失败也弹分享面板)
- 「延迟」判定双端统一到秒级;导出表头、标签文案(「手动」)、「另有 N 天可补记」的可点样式两端一致
