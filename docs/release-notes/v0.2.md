新功能版本：**桌面小组件**（Android + iOS）。

## 桌面小组件

- 内容：今年已记录天数与城市数、今日早 / 晚打卡状态、去过最久的 Top 3 城市；点击进入应用
- **Android**：长按桌面 → 小部件 → TernDays 添加；可横向/纵向调整大小，适配系统深色模式；
  每次打卡、补记、开机后即时刷新，平时每 30 分钟兜底刷新一次
- **iOS**：提供 small / medium 两种规格（长按桌面 → 添加小组件）。通过 App Group（`group.app.terndays`）
  与主应用共享数据，旧版本数据自动迁移；打卡与补记后即时刷新（源码构建，见 `ios/README.md`，仍未真机验证）

## 其他

- 摘要口径（天数 / 城市数 / 今日状态 / Top 城市）抽为共用纯函数并新增单元测试（:core 共 27 个测试）
- Android `versionCode` 2 / `versionName` 0.2；iOS `MARKETING_VERSION` 0.2

安装方式与已知限制同 [v0.1](https://github.com/pekinlcc/TernDays/releases/tag/v0.1)；从 v0.1/v0.1.1 覆盖安装即可，数据保留。
