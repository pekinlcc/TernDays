小组件三种外观全部实现，可在设置里随时切换。

之前定稿只落地了「素面」一种，另外两种停在预览页上。现在三种都做进代码，
**设置 → 桌面小组件 → 外观**一键切换，切完立即生效。

## 三种外观

| 外观 | 长什么样 | 适合 |
| --- | --- | --- |
| **素面**（默认） | 白 / #1C1C1E 实心底，唯一品牌色在年份上 | 任何壁纸都稳，和系统自带小组件同质 |
| **系统材质** | 壁纸透过来 | iPhone 上最好看的一档「隐入桌面」 |
| **品牌渐变** | 品牌色竖向渐变、文字全白 | 一眼认得出，也不挑壁纸 |

三种共用同一套信息层级（年份眉题 + 今年 Top 3 城市三行等权重、城市名 15 / 天数 19–20 / 单位 11），
只换底面与文字配色——切换不会改变布局与可读性。

## 两端的差别（如实说明）

- **系统材质**在 iOS 17+ 是真材质：壁纸由系统实时模糊。iOS 16 没有这个能力，显示为素面。
- Android 小组件是**静态快照**，做不出实时模糊，只能用 90% 不透明的中性底近似；
  在照片类花壁纸上会显脏——设置里的说明写清楚了，觉得脏就切回素面。
- **品牌渐变**在 iOS 18 的着色模式下底色会被系统替换掉（品牌色相消失），这是系统行为。

## 实现方式

- 外观 id（`PLAIN` / `MATERIAL` / `GRADIENT`）进 `:core WidgetStyle`，双端同一套，
  未知值一律回落默认，不会因为降级安装或写坏偏好而崩
- Android：三份布局由同一份模板生成（层级完全一致，只换底面 drawable 与文字色资源），
  颜色写在 XML 里由启动器按它自己的深浅模式解析，比运行时设色可靠
- iOS：主应用与小组件扩展共享 App Group 偏好，切换后立即 reload 时间线
- `:core` 测试 76 → 79
